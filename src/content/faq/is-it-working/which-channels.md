---
question: Which channels are there, and where should I send test messages?
order: 50
---
Everyone shares the default Public channel. Use #testing for radio tests, and send as many messages there as you like.

Hashtag channels have no definitive central list. Anyone who knows the name can join one. Some bots in `#bot` maintain a partial list available by sending the command `!c` to the channel.

See [Channels and use](/join/meshcore-setup/#5-channels-and-use) in the setup guide.
