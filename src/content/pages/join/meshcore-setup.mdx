# MeshCore Setup

## Overview
1. Buy a radio ([our recommendations](/devices/#options))
2. Flash device using your browser: <a href="https://flasher.meshcore.io/" rel="nofollow noopener">https://flasher.meshcore.io/</a>
3. Pick a role:
  - **Companion**: Bluetooth; pairs with your phone to send messages.
  - **Repeater**: No Bluetooth; repeats only. Follow [instructions below](#repeater-config)
4. Use the **USA/Canada Recommended** preset.
5. For repeaters, include alternate contact info in the Owner Info setting such as email, phone, or Discord handle

## MeshCore Setup Walkthrough

### 1) Hardware/Radio

You'll need a radio to get started. Prices range from $13 - hundreds. Many sit in the $30-80 range. MeshCore works on (almost) all the same hardware as Meshtastic.

Find our [suggested hardware on the devices page](/devices/#options).

### 2) Choose a Role: Companion vs Repeater

**Companions** are the radio you'll send messages from. **Repeaters** are coverage extenders that must be configured before mounting.

### 3) Flash the Firmware

1. Open <a href="https://flasher.meshcore.io/" rel="nofollow noopener">flasher.meshcore.io</a>.
2. Connect your device via USB and select the correct port/board.
3. Select the role(typically Companion Bluetooth or Repeater)
4. Enter DFU
  - Recommended: If you plan to install a repeater in a location that is harder to get to(requires a ladder for instance) we strongly recommend flashing the latest [OTAFix](https://github.com/oltaco/Adafruit_nRF52_Bootloader_OTAFIX/releases) before flashing the MeshCore firmware.
5. Erase the device
6. **Flash** the role firmware.
7. For repeaters, click "Repeater Setup" (see below).

### 4) Configure

#### Companion

1. Download the MeshCore app to your phone and pair with your radio over Bluetooth.
2. Set **Region/Preset = US Recommended**.
3. **Do not adjust** frequency, bandwidth, spreading factor, or coding rate.
4. Set your name. This will be visible to others on the network. Set position if desired.
  - **optional:** For advanced debugging and Trace Path analysis, consider setting Hash Size to 2-byte. ([Learn about Hash Sizes](#meshcore-2-byte-vs-1-byte-paths))
5. Send a **Flood Routed Advert** (signal/wave icon at top of app).
6. Remember, you may not see other contacts right away. Allow 24-48 hours for Contacts to populate in your list.

<h4 id="repeater-config">Repeater</h4>

1. After flashing is successful, click **Repeater Setup** on the same page.
  - Set Selected Present to **USA/Canada Recommended**.
  - Set the name and position as desired. Positions are exact.
  - Leave the guest password blank so others change view telemetry and owner info.
  - Set the owner info to include alternate contact information like email, phone, or Discord handle.
  - Set the admin password. Save this somewhere! You'll use it soon.
  - Based on the number of neighbors, tune settings based on the table below.
7. Reboot
8. Send an advert and make sure your new repeater shows up as a contact in your companion device
9. Disconnect your computer, connect solar and battery
9. From your companion node
  1. Log in (tap on the new contact, enter admin password set in the step above
  2. Go to Settings > Sync Clock
10. Deploy/mount the repeater.

##### Neighbor count configuration tuning

Apply the settings that match the number of neighbors your repeater currently sees, entered via the MeshCore app CLI or `meshcore-cli`. As your node sees more neighbors over time, revisit and update these values.

| Neighbor Count           | 0–1 | 2–4 | 5–9 | 10–14 | 15+ |
| ------------------------ | --- | --- | --- | ----- | --- |
| `set txdelay`            | 0.3 | 0.5 | 1   | 1.5   | 2   |
| `set direct.txdelay`     | 0.1 | 0.3 | 0.5 | 1     | 2   |
| `set agc.reset.interval` | 4   | 4   | 4   | 4     | 4   |
| `set multi.acks`         | 1   | 1   | 1   | 1     | 1   |
| `set rxdelay`            | 3   | 3   | 3   | 3     | 3   |

### 5) Channels and Use

1. Austin Mesh uses the default **Public** channel that is automatically configured.
  - Other channels include #meetup, #jokes, #music, #bot, and #testing
3. Send your first message in **Public**. 
  - Does it say "Heard \{x\} repeat(s)"? If so, that means you're connected!
  - If not, try moving your radio. Follow the rule of Height > Antenna > Power.
4. **Send away**! It is perfectly acceptable to send a lot of messages, especially in the #testing channel!
5. Having trouble? [Join our Discord server](https://discord.gg/6a5Sv2s9bG) for more advice.

## MeshCore 2-byte vs 1-byte paths

Every node (radio) on the network gets a nickname. In 1-byte mode that's something like `a1`. In 2-byte mode that's `a1b2`. There are 256 unique 1-byte identifiers. 2-byte has 65,536. This means more nodes can exist without conflicting addresses.

### Explaining key-prefixes

Every node in the mesh has an identifier known as a Public Key. The first characters of that key are treated as an address when routing packets (messages, etc). With a 1-byte hash, there are only 256 possible nicknames to go around. As the network grows, more and more nodes end up sharing the same one address. When that happens, packets may be handed off to multiple nodes instead of only one.

2-byte paths use the first 4 characters of the public key, allowing 65,536 possibilities instead of 256. More room, fewer mix-ups.

### The risks 
1. The max hop limit for a message is reduced from 64 down to 32 with 2-byte. With 3-byte it is reduced further to 21 (64/3).
2. It becomes easier to triangulate a node's physical location by observing the packet paths sent by that radio.
3. Every repeater between you and the person you're messaging has to understand 2-byte addresses, or the message will be dropped. All firmwares after v1.14 support multi-byte hashes.

### Turning it on

#### Repeaters

1. Upgrade firmware to >= v1.14

#### Companions

Companions need an extra step to actually *send* messages using 2-byte paths:

1. Confirm the companion is on firmware 1.14 or later.
2. Find Path-Hash settings in the app
4. Set **Default Path-Hash Size** to 2-byte.
